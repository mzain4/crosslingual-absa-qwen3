# Outputs

Recorded results from the final test runs and values transcribed from the
published M-ABSA tables. The aggregates can be checked against the per-group
rows; the underlying prediction logs are not included here.

All results are on the **test** split, for **3 domains** (Food, Laptop, Phone) x
**6 languages** (en, de, fr, ar, hi, sw) x **2 tasks** (TASD, UABSA), giving 18
domain-language groups per task and 36 groups per system.

## Files

| File                      | Contents                                                                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `per_group_scores.csv`    | 288 rows: one per system x domain x language x task. Raw precision, recall and F1, sample counts, format failures and empty predictions. |
| `summary_means.json`      | Aggregated means per system, domain and task, including the six-language and five-language (excluding English) variants.                 |
| `dataset_statistics.json` | Sentence, aspect and implicit-aspect counts per domain and split, from the pinned repository revision.                                   |
| `error_analysis.json`     | Diagnostic label counts over all 18,912 QLoRA predictions, overall and per task, with the classification priority order.                 |

## Composition of `per_group_scores.csv`

8 systems x 36 groups = 288 rows. The `origin` column separates them:

- **108 rows, `origin = this repository`** — the three strategies compared here:
  `Qwen3-4B zero-shot`, `Qwen3-4B three-shot` and `Qwen3-4B QLoRA`.
- **180 rows, `origin = M-ABSA paper (published)`** — five baselines taken from
  the M-ABSA paper: `mT5-base fine-tuned` and the zero-shot `Gemma-2`,
  `Llama-3.1`, `Mistral` and `Qwen-2.5` results.

`provenance` carries the same distinction in raw form (`experiment` versus
`M-ABSA published result`) for anyone joining against other tooling.

Published rows are **cited values, not local reproductions**. They are included
so the comparison can be re-derived from one file. Do not treat them as
outputs of this code. Their `sample_count`, `format_failures` and
`none_predictions` cells are blank because those quantities are not published in
usable form; the M-ABSA paper prints slightly different sentence counts than the
pinned repository revision, and that difference is disclosed in the paper's
limitations section.

Two F1 columns are present:

- **`raw_f1`** — the metric reported in the paper. Exact-tuple micro-F1 with the
  evaluator's edit-distance repair disabled.
- **`fixed_f1`** — the evaluator's repaired score, kept for completeness and
  **not** used anywhere in the paper.

## Cross-check

Averaging `raw_f1` over the six languages reproduces the headline means in the
paper exactly:

| System               | TASD  | UABSA |
| -------------------- | ----- | ----- |
| Qwen3 zero-shot      | 12.89 | 26.39 |
| Qwen3 three-shot     | 14.49 | 30.33 |
| Qwen3 QLoRA          | 34.51 | 45.06 |
| mT5-base (published) | 25.93 | 43.52 |

That check is what makes these files trustworthy as a record: the reported
numbers are an average of the per-group values, not an independent figure.

## Regenerating

These files contain the recorded results backing the paper. The `clabsa`
implementation uses the pinned model and data revisions recorded in
`src/clabsa/constants.py` and provides the experimental pipeline for
reproducing the local experiment rows. Published baseline rows are cited
values from the M-ABSA paper and are not generated by this repository.
